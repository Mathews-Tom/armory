# Changelog

## 1.0.0 — cross-host native package

This entry describes implemented package/core 1.0.0 behavior. It does not assert that the delivery has already been merged, tagged or published.

- Package Verification Receipts for OMP and Claude Code with contained shared core, bundled executable helpers, native metadata and reproducible artifacts. OMP exposes a package-root `index.ts`; Claude exposes its hooks module through the generated plugin manifest and hooks manifest.
- Run only explicitly configured gate IDs without shell interpolation. Persist exact execution results and bounded private output; separate result, freshly recomputed applicability and proof rather than treating exit zero as unconditional current evidence.
- Register the two literal native commands `/armory-verify` and `/armory-evidence` with asynchronous start, deliberate wait/cancel and actual native session identity. Require explicit repository/configuration/data-root/account/work-context selection through OMP flags or Claude environment values. Reject collisions, invalid arguments and unsafe state without arbitrary command fallback or model turns.
- Own POSIX process groups, bounded TERM/KILL cleanup, root reaping, timeouts and signal cancellation. Reconcile only demonstrably dead committed owners as incomplete/unknown, retaining exact captured hashes without inventing output completeness or descendant cleanup.
- Preserve Claude's conservative `cancellation-unconfirmed` wrapper after stream closure. Stream settlement alone is not proof of descendant cleanup, even when reopened evidence contains a verified durable cancelled receipt.
- Keep receipts partitioned by repository, host, account and work context while allowing new native sessions to reopen history. Store files as 0600 and owned directories as 0700 outside the installed payload. Render safe projections, hashes and stable errors, never credentials, configured commands, private paths, raw output, environment values or exception text.
- Observe covered modifications, untracked additions/deletions, configuration, modes and declared environment/dataset identity. Preserve unrelated freshness; mark changed-during-run inputs unknown. Read supported-schema historical version-mismatched receipts without changing result/output, but report applicability unknown and proof false until rerun.
- Provide explicit host-aware owned install, disable/re-enable, update, rollback through a selected older checkout, and removal. Preserve real receipt data and foreign host state; refuse modified/foreign payloads rather than overwriting.
- Separate credential-free offline CI from explicit fail-closed native qualification. Retain strict pinned native validation/test kits, adapter/core behavior checks, contained reproducible builds and real owned lifecycle tests. Offline success is not authenticated native-host proof.
- Report missing/wrong-version native build tools and unsuccessful or empty Claude version queries as unavailable prerequisites with incomplete acceptance, never a crashed checker, successful qualification or failed feature behavior.
- Require OMP native evidence to carry its own nested artifact-manifest binding; a missing or malformed OMP artifact object cannot borrow Claude's top-level binding field.
- Qualify production-contained artifacts on macOS arm64 with Bun 1.3.14 in OMP 18.12.6 RPC and Claude Code 2.1.309 real interactive TTY. All eight scenario groups passed separately: success/nonzero, reopening, covered versus unrelated freshness, changed-during-run unknown, durable cancellation exit 143 with root/descendant absence, private output hashes/modes and safe native text.
- Require explicit reviewed private 0600 additive Claude settings and a trusted cwd for manual native smoke. Preserve HOME, authentication and enforcement; use no model prompts, persistent owner installation or live-vault writes. Install the dev-only `pyte` parser through `uv sync --locked`.
- Load Claude development artifacts through a separate owned runtime copy: `--plugin-dir` generates SDK types/tsconfig in that copy. Do not delete unknown generated files or weaken lifecycle ownership to accommodate development loading; normal installed-loader behavior is not established by this proof.

Pinned Claude Code 2.1.308 strict offline validation and five native-test-kit cases passed, not native 2.1.308 compatibility. OMP TUI rendering, live ACP command responses, Windows and Linux-native execution remain unproven. OMP 18.12.6 ACP's inspected live-text limitation is not satisfied by historical session replay.
