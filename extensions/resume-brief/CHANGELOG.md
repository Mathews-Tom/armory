# Changelog

## 1.0.0

Package and shared core versions are 1.0.0. This entry records exercised behavior, not merge, publication or tagging.

- Add the pure Resume Brief core: strict parsers for the `armory.resume-brief.context/v1` and `armory.resume-brief.blockers/v1` artifacts, OMP JSONL session headers (version 3) and handoff file names, and allowlisted Verification Receipts schema-1 reference fields; card construction; approval hold evaluation; field-level discrepancy rules; inert text rendering; and strict snapshot validation. The core has no runtime, filesystem, clock or host imports.
- Add bounded helpers that read only explicitly selected sources: descriptor-pinned `openat` traversal for repository-relative files on macOS/glibc Linux, and absolute OMP session, handoff and receipt files. Refuse special files, oversize content and identity changes during a read; record Git branch, `HEAD` and upstream before and after reading sources. Never run repository-configured fsmonitor, conversion or signature commands; keep repository-wide dirty state unknown and compare selected-plan raw bytes with the raw `HEAD` blob.
- Add the standalone `record`, `reopen`, `show` and `list` CLI with JSON and escaped text output. Reopen re-reads the recorded selection and reports source-linked discrepancies with recorded and current SHA-256 values; it never resumes or executes anything.
- Keep every approval a non-executable hold. Expiry cannot be renewed by a fresh source read, and approvals from another or unknown host, account or session are marked foreign.
- Persist only derived snapshots under an explicit external data root as owned 0700 directories and exclusive 0600 files, preserving earlier snapshots and refusing tampered, linked or foreign state. No plan, handoff, receipt or transcript bodies are stored.
- Use immutable `snapshot/v2` for native-session observations. Earlier standalone-prefix `snapshot/v1` caches are refused, not migrated or overwritten; preserve the old root and select a fresh external private root before recording from the original sources.
- Accept native OMP version-1 title slots without retaining their contents and preserve all valid shipped Verification Receipts gate references, including 256-character references. Retain recorded source pointers when current selection becomes unavailable; render invisible Unicode tag and variation-selector content visibly escaped.
- Reject prototype-named unexpected snapshot fields; isolate inherited Git repository/object/history-file overrides when observing the explicitly selected worktree while retaining discovery limits and user configuration; refuse new snapshot publication at the listing limit and classify malformed private filenames as rejected without replacing existing state.
- Pin private-state creation, enumeration, reads and durable no-clobber publication to no-follow directory descriptors. Reject replaced directory identities before accessing state; leaf/ancestor replacements cannot redirect publication or expose another directory's snapshots. Use platform-correct private temporary creation on macOS.
- Add explicit `/armory-brief` OMP and Claude Code adapters, inert native text and JSON rendering, current host session identity and bounded Claude host-API session projection. Reopen refuses changed configured selection rather than silently expanding recorded scope. Session transitions revoke publication into replacement contexts.
- Preserve machine-readable JSON refusals for valid native `--json` commands, including configuration failures, scope transitions and invalid or truncated helper answers, without exposing helper stderr or foreign exception text.
- Add self-contained host artifact metadata, meaningful static eval cases, host-aware owned install/update/disable/re-enable/remove instructions and historical-study EXCLUDED classification without changing the frozen sample or treatments.
- Qualify detached OMP 18.12.6 RPC and Claude Code 2.1.309 interactive/headless text on macOS arm64. Preserve normal HOME/default authentication and all user/managed enforcement, use disposable feature/artifact roots and reviewed optional-writer controls, and distinguish native proof from credential-free CI. Headless Claude emits its `resume-brief: ` prefix before the JSON payload; process exit 0 alone does not imply a successful observation. SDK, installed-Claude-loader, OMP TUI/ACP, other versions/platforms and injected in-flight cancellation remain unqualified.
- Not included: automatic resumption, executable approvals, live pull request state, receipt freshness recomputation, transcript/body copying or snapshot pruning.
